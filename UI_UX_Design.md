UI/UX Design

Overview

The UI/UX design of the Safarino mobile application was created with the goal of providing a simple, modern, and user-friendly experience for travelers. The interface was designed to help users search, explore, and book travel services with minimal effort while maintaining a clean and visually appealing layout.

Color Palette

A green color palette was selected as the primary theme of the application to represent nature, trust, comfort, and travel. Neutral shades of gray and white were combined with the primary color to create visual balance and improve readability. The consistent use of colors throughout the application strengthens the brand identity and provides users with a familiar experience across different screens.

Icons and Visual Elements

Simple and recognizable icons were used to improve navigation and reduce the learning curve for users. Each icon represents a specific travel service, such as flights, hotels, trains, buses, and user profile sections. Visual consistency was maintained by using icons with similar styles, sizes, and spacing throughout the interface.

Typography

Readable typography was selected to ensure a comfortable reading experience on mobile devices. Different font weights and sizes were applied to establish a clear visual hierarchy, allowing users to quickly identify important information such as destinations, prices, and action buttons.

Screen Design

The application consists of multiple interconnected screens, including Login, OTP Verification, Home, Hotel Listings, My Trips, User Profile, and Safarino Pro. Each screen was designed with a clear purpose and organized layout to minimize user confusion and simplify navigation.

Special attention was given to spacing, alignment, and component consistency. Cards, buttons, navigation bars, and input fields follow the same design language across the entire application, creating a unified and professional user experience.

User Experience Considerations

Several UX principles were considered during the design process:

- Simple and intuitive navigation.
- Consistent visual hierarchy.
- Easy access to frequently used features.
- Minimal cognitive load through clean layouts.
- Responsive spacing and touch-friendly interface elements.
- Consistent branding across all pages.

Conclusion

The overall design focuses on usability, consistency, and visual clarity. By combining a modern color scheme, intuitive icons, organized layouts, and user-centered design principles, the Safarino application provides an engaging and efficient experience for users planning and managing their travel.
